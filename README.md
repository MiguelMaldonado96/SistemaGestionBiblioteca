# Sistema de Gestión de Biblioteca

Aplicación de escritorio para administrar la información y los procesos de una biblioteca educativa. El proyecto se desarrolla como trabajo final de Programación Avanzada.

## Tecnologías

- C#
- Windows Forms
- SQL Server
- Git y GitHub

## Módulos previstos

- Libros
- Autores
- Editoriales
- Usuarios
- Préstamos y devoluciones
- Consultas y reportes

## Arquitectura

La solución separará las responsabilidades de presentación, lógica de negocio y acceso a datos. La base de datos relacional almacenará las entidades y sus relaciones, con claves y restricciones de integridad.

## Convención de nombres

Los nombres de variables serán descriptivos, en español y con formato `camelCase`.

## Estado

En desarrollo. La estructura de la solución, el modelo de datos y las instrucciones de configuración se completarán durante la implementación.
